# 奥维地图后台自动化

先分清是离线 GIS 计算，还是已授权的奥维收藏夹操作。离线任务直接使用本包 `scripts/ovital/` 的几何与 KML 模块，不必启动奥维，更不需要 ArcGIS 进程或许可。应用读写复用官方 Windows 消息接口与隐藏回调会话，不默认点击坐标或抢鼠标键盘。

## 入口

- 初次迁移、依赖、模块调用与版本/权限检查：读 [接收方配置](references/receiver-setup.md)。本包带执行代码，复用它，不从流程文字重写一套。
- 收藏夹树、Track/Shape/Group、后台创建修改、保存与独立读回：读 [原生操作边界](references/native-workflow.md)。具体参数以包内 CLI `--help` 和对应模块签名为准。
- 道路封面、外扩、裁切、孔洞、计量、影像配准或新旧版本合并：读 [几何处理与已排问题](references/geometry-lessons.md)。不要把历史工程的宽度、偏移距离、地图源、级别、ID或目录当默认值。

## 执行与验收

1. 绑定本次输入、完整父路径、目标对象、允许修改范围、输出位置和保存方式。先读当前对象，不根据同名或旧脚本猜身份。
2. 使用正确坐标系与米制计算基准，先核物理对象边界，再进行偏移。返回几何有效不代表影像判读正确。
3. 先在离线副本算出结果，核来源覆盖、有效性、面积/长度口径及差异；原始来源保留。删除或替换只针对已批准的明确对象。
4. 原生写入逐步记录回执；部分成功后只续未完成步骤，不重放整个旧发布程序。对未知返回先独立读回再决定，不盲目重试创建。
5. 分别核 API返回、对象几何/样式、持久化保存、独立会话读回。保存动作针对整个收藏夹，可能连带用户其他未保存修改，须先说明并取得对应保存授权。不能用 `SAVE_CFG` 冒充收藏夹已持久化；若当前版本无已验证后台保存入口，停止该步并明确交回，不用前台快捷键顶替。

地图数据导出只请求已有缓存，核图源、级别、坐标范围、瓦片和实际输出；图源访问权限及地图许可由接收方自行确认。官方地图数据接口当前注明需 SVIP。不能把缓存影像的像素放大当成真实测绘精度。

## 安全默认与结果

安装、测试或读取不授权写入真实收藏夹。用户自行安装奥维并登录；不索取账号、验证码或数据库。不得原样运行作者的工程发布脚本，不自动扫描全部收藏夹来清理同名项。

本包以合成几何、序列化和假传输测试验证可迁移代码；源工程曾有真实后台读写/保存记录，但本次新包未对接收方奥维进行实写验收。报告完成、失败、部分成功及未验证条件；几何检查、原生保存和用户视觉验收分别陈述。
